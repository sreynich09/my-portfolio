# My Portfolio

A personal portfolio website made with Vue 3, Vue Router, and Tailwind CSS.

## Features

- **Home** — a welcome section with a short intro and a button
- **About** — my story, my skills (with icons), and my education
- **Projects** — a list of projects I made, with tech tags
- **Contact** — a form that checks your input and shows a success message
- **404** — a custom page for wrong links
- A nav bar that works on mobile and shows the active page

## Tech Stack

- [Vue 3](https://vuejs.org/)
- [Vue Router](https://router.vuejs.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Vite](https://vite.dev/)

## Getting Started

Install the packages:

```sh
npm install
```

Start the app:

```sh
npm run dev
```

Build the app for production:

```sh
npm run build
```

Check the code for errors:

```sh
npm run lint
```
